# IGW 1.6.58 发布说明

发布日期：2026-09-16

## 百万点工程按需访问

- 工程配置进入时先读取工程树摘要和点位总数；超过 5 万点自动使用分页编辑器，不再请求完整工程 JSON。
- 未展开的工程节点不会读取其子节点，未打开的标记组不会把点位下载到浏览器。
- 直接在浏览器访问旧的完整工程地址时会跳转到工程配置页面；API 客户端仍收到明确的 413 提示，避免误下载超大工程。
- SQLite 仓库新增轻量点位计数查询，模式判断不再依赖运行时已采集点数。

## QC 现场信号检查

- 大范围和搜索结果每页最多加载 1000 个点，只有当前页建立实时订阅。
- QC 支持按名称、实际地址、说明和完整路径在服务端搜索，并支持上一页、下一页浏览。
- 1 万点以内的小范围继续渐进加载，保留原有快速查看体验；大范围严格分页，避免浏览器因数十万点渲染和订阅而卡死。
- 工程发生变化后会重新读取当前范围并恢复实时流，不读取未打开范围。

## MES 模板管理

- 流程模板面板改用紧凑目标目录，只读取可套用组、任务状态和模板名称，不再下载整个工程点表。
- 目标目录保留 OPC UA 主组与子组选择规则，以及设备模板实例信息。

## 验证

- 百万点 SQLite 基准：导入 1000000 点后数据库约 393 MB，分页查询 P50 约 116 ms、P95 约 139 ms，单点更新约 20 ms。
- 后端完整测试：1602/1602 通过。
- 前端完整测试：75 个测试文件、338 项通过。
- 解决方案编译和前端生产构建通过，编译结果 0 警告、0 错误。
- 安装器自动化测试：11/11 通过；Runtime、独立日志服务及 OpenObserve 1.0.0 Windows 包完整性通过校验。
- 本次没有修改 S7 Plus 原生代码；当前电脑的 Visual Studio C++ 安装缺少 MSVC 标准头文件和库，因此安装包沿用已验证的 `igw_s7plus.dll`，SHA-256 为 `11364AE4AF70DC3A18B4E4C554F2B7E2211383FB26F3286F33B2F42AACCFD615`。前端、Runtime 和日志服务均从当前源码重新发布。
