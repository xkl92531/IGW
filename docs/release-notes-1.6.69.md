# IGW 1.6.69 发布说明

打包日期：2026-09-18。平台：Windows x64，自包含 .NET 10 运行时。

## 工程保存性能

此前工程整体保存会清空并重写数据库快照，随后停止并重启全部北向组件。点位备注还参与通信配置签名，因此小改动也可能触发设备重建，叠加停止等待和 OPC UA 服务重建耗时。

- 工程层级、名称和顺序不变时，差异更新通道、设备、分组和点位，跳过未变化的记录及配置区段；结构或名称变化保留完整快照保存路径。模板和 MES 任务按发生变化的集合保存。
- 点位、分组、设备、通道和设备模板的备注不再参与通信重建判断。备注仍会保存，并同步到现有点位定义及 OPC UA 节点说明。
- 仅修改 MES、历史、MQTT、定时计划或 OPC UA 配置时，只重载对应组件。实际点位定义、模板通信参数或计算点变化仍重建必要的设备或消费组件。
- 备注保存保留已有设备连接、缓存值、点位句柄和实时流。保存仍等待持久化及必要的运行时应用完成后返回成功。
- 保留事务、版本冲突检查和敏感配置加密；不改变既有写入重试限制与按任务配置执行的采集周期。

## 本地验证

- 后端全量测试：1,790 项通过，0 失败，0 跳过。包含差异落库、加密配置往返、版本冲突、连接与缓存保留、关键配置重建和组件选择回归。
- 前端类型检查与生产构建通过；本版没有修改前端源代码。
- 安装脚本测试：12 项通过；原生 DLL 离线 Release 构建通过。
- Runtime、日志服务及 OpenObserve 发布布局检查通过；两个服务程序集版本均为 `1.6.69.0`。24 个网页文件及 48 个压缩副本校验一致，原生 DLL 与 Release 构建产物一致；发布目录未包含工程、数据库或密钥文件。
- 同一组 4 万点隔离测试中，数据库再次保存耗时从约 2.76 秒降至 0.44 秒。
- 4 万模拟点位、启用本机 OPC UA 服务时，完整后端保存调用：工程备注约 2.07 秒、单点备注约 1.51 秒、MES 配置约 1.21 秒；上述调用保留了已有引擎、调度器和实时流实例。

上述耗时来自本机模拟工程，不含浏览器上传耗时，未连接现场 PLC。现场反映的约 20 秒保存问题需要部署后确认改善幅度；结构修改或真实通信配置变化仍可能需要等待相关组件停止和重建。
