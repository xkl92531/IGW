# IGW 1.6.52 发布说明

发布日期：2026-09-13

## 日志异常修复

- 修复 OpenObserve 实际使用 `severity` 字段时，错误和警告筛选返回 502、详情把 Error 显示成 INFO 的问题。
- 修复授权未通过或运行数据流不可用时，前端持续重连并反复产生 SignalR 503 日志的问题。运行数据不可用现在作为明确的终止状态显示，工程重新加载仍会按原逻辑重试。
- IGW 主动返回的 SignalR 协议异常只保留一条结构化摘要，过滤框架随后产生的重复异常；摘要保留接口、操作、HTTP 状态、错误代码和耗时，不把编码后的长响应体写入异常消息。

## 日志阅读体验

- 面向普通用户把 Trace ID 改为“排障编号”，并标明“技术支持使用”；常用搜索框不再要求用户理解 Trace ID，高级筛选仍可按排障编号精确查询。
- 长接口地址、请求内容、响应内容和结构化字段默认显示三行摘要；可展开全文，在限定高度内滚动，也可一键复制未截断的完整原文。
- 超过 12000 个字符或 200 行的上报内容进入全屏大内容查看器，每段最多渲染 400 行；支持按标记名、字段或值搜索并自动跳转，支持上一处/下一处、分段翻页、复制全文和下载原始 JSON/TXT。3000 个标记节点的回归用例确认主详情不会直接渲染全部内容。
- JSON 内容会自动格式化后展示，复制时仍复制原始内容；详情抽屉加宽并补充窄屏单列布局。
- 日志级别兼容 OpenTelemetry 的 `Information`、`Warning`、`Error`、`Critical` 等实际值，列表、详情和筛选保持一致。

## 本机运行日志检查

- 对当前已安装版本最近 24 小时的 3096 条日志做了分页核对：2454 条 Information、321 条 Warning、321 条 Error。
- 主要异常为 311 次运行数据不可用导致的 SignalR 实时流结束，以及对应的框架重复异常；另有少量授权已到期导致的诊断接口 503。采样范围内未发现 PLC、OPC UA 或数据库崩溃记录。
- 当前机器运行的是旧构建 `f62b64d54e99731b6324649c22423c932824e2e2`；上述降噪和级别修复需要安装本版本后才会生效。

## 验证

- 后端完整测试：1595/1595 通过。
- 前端完整测试：73 个测试文件、327 项通过；TypeScript 类型检查和生产构建通过。
- 页面回归确认模块、功能、排障编号及长内容操作能够正常呈现。
- 端口选择测试改为注入明确的空闲/占用条件，避免本机正在运行的 OpenObserve 影响测试；生产环境仍会真实检测 28020/28021，冲突时自动选取下一组连续端口。
- 本次未连接现场 PLC，也未修改 S7 Plus 原生驱动；安装包继续复用已验证的 `igw_s7plus.dll`。
