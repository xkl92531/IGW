# IGW 1.6.56 发布说明

发布日期：2026-09-13

## 日志报文滚动体验

- “实际接口报文”展开后只保留正文区域的一条滚动条。
- 移除外层报文卡片的固定高度和滚动，避免两条相邻滚动条互相争抢滚轮。
- 长报文仍由正文查看器限制可视高度；分页、复制全文和下载完整报文功能保持可用。

## 大工程标记自动补全

- 已填写标记的选择框打开时，从“候选列表 + 精确校验”两次请求合并为一次针对当前完整路径的请求。
- 自动补全查询不再先对全部匹配标记执行 `COUNT(*)`，直接读取最多 101 条并判断是否需要提示继续缩小范围。
- 保留 250 ms 输入防抖、旧请求取消、最多 100 个返回候选和虚拟列表渲染，降低几千至十万标记工程连续输入时的数据库与界面负载。
- 其他需要准确总数的工程分页查询仍执行计数，不改变原有分页语义。

## 兼容性

- 本次没有连接现场 PLC，也没有改动 S7 原生驱动；安装包沿用已验证的 `igw_s7plus.dll`。
- 标记选择仍支持手工输入；读写权限、跨 PLC 写入限制和 OpenProtocol 命令校验保持不变。

## 验证

- 后端完整测试：1601/1601 通过，其中包含 10 万标记工程的索引搜索用例。
- 前端完整测试：74 个测试文件、336 项通过。
- TypeScript 类型检查和前端生产构建通过。
- 安装器自动化测试：11/11 通过。
- Runtime、独立日志服务、OpenObserve 1.0.0 Windows 包及许可证完整性通过校验。
