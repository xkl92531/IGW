# IGW 1.6.72 发布说明

打包日期：2026-09-18。平台：Windows x64，自包含 .NET 10 运行时。

本版在 1.6.71 基础上修复了“只保存改动”引入的问题。**1.6.71 不要部署，请直接使用 1.6.72。** 1.6.71 的全部功能（保存提速、流程操作历史、写入失败明细、QC 毫秒刷新、版本号显示等）见 `release-notes-1.6.71.md`。

## 修复

- **保存工程可能丢点位**：一次保存里删掉一个组、新建同名组、再把原来的子组挪进去时，子组下没改过的点位会被数据库连带删除。现在被移除的组、设备、通道改在最后删除，挪走的内容不会受影响。
- **采集任务从列表中消失**：采集任务引用的组被删掉重建，或者任务先建好、对应的组后加上，而任务本身没改时，任务和组、点位之间的关联不会更新。按设备、通道筛选采集任务时会漏掉这个任务。现在只要组或点位有结构变化，保存时就按路径重新关联。
- **重复 id 静默覆盖**：同一张表里出现重复的通道、设备、组或点位 id（例如复制粘贴带出原 id）时，后一份会覆盖前一份。现在重复出现的那一份自动分配新 id。
- **超大流程的操作历史**：单份流程快照超过约 4 MB 时不再记录操作历史，避免浏览器内存占用过高。历史面板里会有提示。
- **回写失败标题**：上报业务失败时，响应直写节点的详情标题会显示英文 “idle”，现在显示“回写失败”。
- 更新了 3 项与现行实现不一致的前端静态测试（参数选择器按需校验、模板目标由服务端目录提供）。

## 本地验证

- 后端全量测试：1,799 项通过，0 失败。新增级联删除、MES 关联、重复 id 三个场景的测试。
- 前端：类型检查通过；vitest 370 项、静态检查 234 项全部通过。
- 本机模拟 PLC（5 台 PLC）：新增、删除点位时保存约 1.9 到 2.1 秒，无改动时约 1.5 秒；保存后 5 台 PLC 全部重新连上。
- 发布目录中的程序集版本为 `1.6.72.0`。
