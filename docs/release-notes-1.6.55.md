# IGW 1.6.55 发布说明

发布日期：2026-09-13

## HTTP 实际请求与响应

- REST 接口日志现在关联客户端发给 IGW 的实际请求和 IGW 返回给客户端的实际响应。
- GET 请求会显示完整路径和查询参数，并明确标注“无请求正文”；POST 等文本请求会显示实际正文。
- 请求与响应报文保存在本机载荷文件中，OpenObserve 只索引报文编号和字节数，日志详情按每页 32768 个字符加载，也可下载已保存报文。
- 单个请求正文和响应正文分别最多保存 8 MB；超过上限时明确标注截断，但客户端仍收到完整响应。
- JSON、XML 和文本响应支持正文捕获；实时流与二进制响应不缓存正文，避免影响长连接、工程导入导出和诊断包下载。
- 日志报文保存失败不会改变接口状态或返回内容。

## 日志详情布局

- “实际接口报文”移到结构化字段之前，打开接口事件即可先查看发送内容和返回内容。
- 升级前产生、没有关联报文的历史接口日志会明确提示无法补录。
- 长英文原始字段名允许在字段列内断行，不再覆盖右侧字段值。
- 报文操作按钮、页码信息在窄抽屉中自动换行，避免控件挤压重叠。

## 敏感信息与兼容性

- Authorization、Cookie、密码、令牌、API Key、URL 用户密码继续在本机落盘前脱敏。
- 新增 URL 查询参数中 `access_token`、`refresh_token` 和 `id_token` 等凭据脱敏。
- 本次没有连接现场 PLC，也没有改动 S7 原生驱动；安装包沿用已验证的 `igw_s7plus.dll`。
