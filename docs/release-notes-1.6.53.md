# IGW 1.6.53 发布说明

发布日期：2026-09-13

## 接口实际报文

- MES HTTP 接口日志现在关联本机报文文件，记录真正送出的冻结 JSON、HTTP 响应状态和实际响应正文；超时、取消和连接失败也会保留当次已发送内容。
- 报文正文不写入 OpenObserve 索引，避免几千个标记节点撑大检索数据。日志详情自动读取第一页，每页最多 32768 个字符，可分页预览或下载完整报文。
- 接口日志新增发送字节数和响应字节数。内部报文编号不再作为普通结构化字段展示。
- Authorization、Cookie、password、token、secret、apiKey 以及 URL 用户密码在本机落盘前脱敏；报文保存失败不会改变接口结果、业务判定或 PLC 回写。
- 报文文件跟随日志保留周期每 6 小时清理一次，避免脱离 OpenObserve 日志长期累积。

## 采集性能详情

- 恢复独立的“采集性能”顶部入口和完整页面，继续显示设备周期、完成间隔、P95、协议请求、会话、网络证据、归因和批次明细。
- 日志中心的性能分类继续保留实时诊断，并新增“打开完整采集性能页”入口，窄区域查看日志与完整诊断互不影响。

## OpenObserve 专业入口与字段显示

- IGW 日志中心的“日志设置”现在显示当前电脑实际生成的 OpenObserve 本机地址、登录账号和密码，可直接打开、显隐或复制；每台网关使用不同凭据。
- 凭据接口仅接受网关本机请求且禁止浏览器缓存，远程访问 IGW 时不会返回管理密码。页面提示 OpenObserve 属于底层专业诊断工具，日常排障优先使用 IGW 日志中心。
- 日志详情中的结构化字段统一使用中文名称；重复的 OpenObserve 时间、正文、级别等外层字段不再重复显示，未知技术键显示为“扩展字段”并保留鼠标悬停原始名称。

## 验证

- 后端完整测试：1598/1598 通过。
- 前端完整测试：73 个测试文件、333 项通过；TypeScript 类型检查通过。
- MES 报文关联、JSON 敏感字段脱敏、32K 分页、报文保存失败隔离和性能独立路由均有自动化回归。
- 本次未连接现场 PLC；PLC 性能页面读取现有运行时诊断快照，不会额外访问 PLC。
