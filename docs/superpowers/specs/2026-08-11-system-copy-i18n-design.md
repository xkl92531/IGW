# IGW 系统文案国际化补漏设计

日期：2026-08-11

## 目标

补齐英文模式下仍显示中文的 IGW 系统文案，覆盖工程树、MES 采集流程弹窗标题和授权状态卡。用户创建的通道、设备、DB、点位、客户名称及第三方错误原文保持不变。

## 根因

- 工程树根节点、采集标记和 MES 弹窗标题直接拼接中文，没有经过语言服务。
- 设备/通道运行状态工具返回已经拼接完成的中文，调用页面无法再翻译。
- 授权卡直接显示 Runtime 返回的中文 `message`，即使状态标题已调用 `t()` 仍会中英文混排。

## 设计

- 工程树系统节点和采集标记统一通过 `t()`；业务对象名称原样显示。
- 运行状态工具接受可选翻译函数，默认保持现有中文输出，工程树传入当前语言服务。动态计数使用参数化词条，原始通信错误只翻译“原因”前缀。
- MES 弹窗只翻译固定标题和空名称回退，DB 名保持原样。
- 授权卡根据结构化 `status`、`expiry` 和 `daysLeft` 生成本地化状态与说明；未知状态才回退 Runtime 原始消息。“本机试用”作为 IGW 系统客户名翻译，真实客户名保持原样。

## 验收

- 英文模式下显示 `Project`、`Connectivity`、`Collecting`、`Offline`、`MES Collection Flow` 等英文系统文案。
- 授权卡的状态、试用客户名和有效期说明不再混入中文。
- 中文模式输出和既有状态判定保持兼容。
- 相关 Node 测试、类型检查和 Vite 生产构建通过。
