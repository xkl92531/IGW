# IGW 通道重连与实时诊断设计

## 目标

在工程配置的通道右键菜单中提供可靠、快速的“立即重连”，修复诊断窗口状态不更新和误报离线的问题，并移除 IGW Runtime 内置模拟模式。独立的多协议 PLC 模拟器不属于删除范围。

## 已确认根因

工程树每 3 秒更新共享的 `runtimeDevices`，但诊断窗口打开时把 `/api/v1/devices` 复制到独立的 `diagStatus`，之后不再同步。因此设备连接状态发生变化后，工程树已在线，诊断窗口仍显示打开瞬间的旧状态。

## 通道立即重连

- 通道右键菜单增加“立即重连”。
- Web UI 调用新的通道重连管理接口，传递通道名称。
- Runtime 在生命周期互斥锁内，仅停止并重建该通道的设备运行循环。
- 重建会清除该通道设备当前的连接退避、熔断和故障状态；其他通道、工程配置和 MES 任务不重载。
- 如果设备存在采集或数据消费需求，新循环立即开始连接；如果没有需求，设备保持 `Standby`，不为了手动重连而持续占用 PLC 连接。
- 接口返回重启设备数；通道不存在返回 404，运行时未就绪或正在重载返回明确错误。
- 前端防止重复点击，成功后立即刷新运行状态，并在短时间内继续轮询状态变化。

## 诊断窗口

- 删除独立的 `diagStatus` 快照，诊断表直接使用工程树的共享 `runtimeDevices`。
- 打开诊断窗口时立即触发一次状态刷新；窗口打开期间继续沿用全局 3 秒轮询，因此状态会实时变化。
- 手动“刷新”按钮调用同一个状态刷新函数。
- 加载失败时保留上一次已知数据并展示错误，而不是静默清空后误报“未下发”。
- 诊断状态与工程树共用 `findRuntimeDevice` 和 `effectiveRuntimeState`，避免同一设备在两个位置显示不同结论。
- 显示最近更新时间、连接细分信息和最近通信错误。

## 移除 IGW 内置模拟模式

- 删除 Web UI 通道右键入口、通道摘要按钮、设置项和模拟模式弹窗。
- 删除前端模拟状态分支，所有在线状态以 Runtime 真实设备状态为准。
- Runtime 不再因为遗留 `settings.simulate=true` 把真实驱动替换为 `Simulator`；旧工程中的残留字段被忽略。
- 新建和编辑通道不再生成 `simulate`、`simSpeed`、`simDelayMs`。
- Runtime 不再注册内置 Simulator 驱动；保留源项目文件以避免扩大到无关的仓库物理清理。
- 独立 `YanJing.NK.PlcSim` 工具及其 OPC UA、S7、Omron 模拟能力不受影响。

## 测试

- Runtime 单元测试：只重启目标通道、其他通道保持原循环、无需求设备重启后待机、未知通道报错。
- REST 测试：重连接口路径、成功返回和错误状态。
- Web UI 源码/逻辑测试：菜单存在重连且没有模拟入口；诊断使用共享状态；错误不再静默清空。
- 回归：IGW.Tests 全量、Vue 类型检查、Vue 生产构建、Runtime 构建。

## 非目标

- 不修改 PLC 协议驱动自身的连接超时参数。
- 不强制无采集需求的设备常连。
- 不重载整个工程或其他通道。
- 不删除独立 PLC 模拟器。
