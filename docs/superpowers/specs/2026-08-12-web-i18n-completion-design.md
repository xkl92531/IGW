# IGW Web 管理端国际化补全设计

日期：2026-08-12

## 目标

补全 IGW Web 管理端的中英文切换，使工程配置及其全部子向导、弹窗和提示在切换英文后不再残留固定中文。范围仅限 Web，不修改 WPF 桌面配置器。

## 覆盖范围

- 工程配置主页面、工具栏、树菜单、右键菜单和空状态。
- 新增通道、设备、标记组、标记向导。
- 工程、通道、设备、标记组和标记属性编辑器。
- OPC UA 浏览、Siemens 身份验证、CSV/KEP/DB 导入预览。
- 通道诊断、模板管理、验证报告及工程配置调用的其他 Web 子弹窗。
- 固定按钮、标题、字段名、帮助说明、提示消息、确认框、下拉选项和状态文案。

## 不翻译内容

- 用户输入的工程、通道、设备、DB、结构体和点位名称。
- PLC 原始变量名、地址、NodeId、接口字段名和协议标识。
- PLC、MES、驱动及第三方组件返回的原始错误正文。
- 用户自定义描述和业务文本。

原始错误外围的固定说明需要翻译，例如英文界面显示 `Connection failed: <原始错误>`，其中前缀翻译，原始错误保持不变。

## 实现方案

### 固定文案

所有面向用户的固定中文必须通过现有 `useI18n()` 的 `t`/`tr` 或模板 `$t` 输出。动态句子使用命名参数，不在模板中拼接不可翻译的中文片段。

### 配置枚举

工程文件中的既有枚举值保持不变。例如 `启用/禁用`、`是/否` 和中文扫描模式仍以原值保存，界面用 `{ value, label }` 显示翻译后的标签。切换语言不得修改配置、产生脏数据或破坏旧工程兼容性。

### 字典

缺失固定文案加入英文目录。英文值不得残留中文操作文案；协议名、产品名及用户数据不受此规则约束。

### 守门测试

新增 Web 国际化审计测试，扫描工程配置功能域及其组件：

- 检测模板文本、可见属性、消息框、通知和向导元数据中的裸中文。
- 允许注释、测试说明、语言目录键、协议示例、正则表达式和明确标注的原始数据。
- 对配置枚举断言“保存值不变、显示标签可翻译”。
- 对新增字典键检查英文值存在且不含遗留中文操作文案。

测试必须先对当前代码失败，再实施修复。

## 运行时验证

1. 切换英文并刷新页面，语言偏好仍从数据库恢复。
2. 打开新增通道向导，逐步检查类型、名称、通信参数和汇总页。
3. 打开新增设备向导和通道/设备属性编辑器，检查分类、字段、下拉项和帮助文本。
4. 打开工程、标记组、标记属性以及导入、诊断、浏览和验证弹窗。
5. 切回中文，确认配置内容和用户命名未发生变化。

## 完成标准

- Web 工程配置功能域不存在未经豁免的固定裸中文。
- 中英文切换不改变工程配置值。
- 国际化审计测试、现有前端测试、类型检查和生产构建全部通过。
- 实际页面检查覆盖新增通道、新增设备、属性编辑器及至少一个导入/诊断弹窗。
