# QuestDB 日志中心

用户已选择 QuestDB。Windows 和 Linux 均使用固定版本 10.0.1 官方自带 Java 的运行包；现场离线安装，不要求 WSL、Docker 或另装 Java。IGW 管理子进程，数据库仅监听回环地址，凭据复用本机受保护的观测配置。

新日志异步批量写入 WAL 表，小时分区、默认保留 30 天；每天 3000 万条、30 天 9 亿条是容量评估目标，不是未经压测的性能承诺。采集线程仅入有界内存队列，后台先写成批次磁盘缓存再发送，失败重试使用稳定 UUID 去重。缓存有容量上限，超限和磁盘失败必须在状态中显示，不等待数据库拖慢 PLC。接口报文也进入数据库，保留旧报文读取兼容。

保持日志中心 API、分页、字段筛选、区分大小写的关键词、工程路径边界、趋势、导出和载荷读取。旧分段通过后台有进度导入，稳定 ID 保证中断后重跑不重复；源文件不因导入删除。导入未结束时状态明确标记，避免将历史不全报告为完整。

安装包捆绑数据库和许可证。目录迁移必须暂停数据库访问、停止所有拥有的数据库进程、复制完整数据并重新启动，失败回到原目录；期间日志继续入缓存。禁止对正在写入的数据库直接复制当作一致备份。默认保留期按完整分区清理，可能多保留一个小时。实时查询监视 WAL 应用延迟。

本次在独立工作树实施和验证，不更改现场 6.75 服务，也不合并 master。旧 Windows 的兼容范围以 .NET 10 和捆绑 Java 实测为准。
