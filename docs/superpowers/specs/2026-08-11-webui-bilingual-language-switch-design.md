# IGW Web UI 中英文切换设计

日期：2026-08-11

## 目标

IGW Web UI 支持 `中文` 与 `English` 即时切换。顶栏是唯一入口；点击后立刻切换并自动保存到网关 SQLite 偏好数据库，刷新、F5、Ctrl+F5 和 IGW 重启后继续使用上次语言，不提供额外的“应用”或“保存”动作。浏览器本地存储仅作为 Runtime 暂时不可用时的启动兜底。

默认语言为中文。首次访问且没有保存记录时使用中文。

## 方案选择

采用 IGW 内置的轻量类型安全语言服务：集中维护中英文目录，通过 Vue 的 provide/inject 暴露响应式语言状态和翻译函数，并由根组件动态配置 Element Plus 语言。

没有采用以下方案：

- `vue-i18n`：能力完整，但当前只需要两种语言和简单参数替换，新增依赖和包体积没有必要。
- DOM MutationObserver 自动替换中文：改动看似少，但会与 Vue 更新、输入框、画布和动态消息冲突，不能作为生产方案。

## 交互设计

- 顶栏右侧、连接状态之前增加紧凑的地球图标语言菜单。
- 中文状态显示 `中文`，英文状态显示 `EN`。
- 菜单选项为 `中文` 和 `English`，当前语言有明确选中标记。
- 点击选项即刻更新页面、`<html lang>`、Element Plus 语言，并异步写入网关偏好数据库；写库失败不回滚当前界面，但会提示用户。
- 不刷新页面，不重载工程，不中断采集和流程运行。

## 翻译边界

必须翻译：

- 顶栏、导航、连接与授权状态。
- 工程配置、监控中心、IGW 设置三个正式路由的按钮、标签、提示、空状态和确认框。
- MES 画布、节点详情、数据范围、参数选择器、模板和 OPC UA 浏览等正式弹窗。
- Element Plus 内置分页、日期、选择器、上传、空数据和校验文案。

不得翻译：

- PLC、通道、设备、DB、结构体和点位名称。
- PLC 中文注释、用户自定义标题、模板名称和工程数据。
- MES 接口返回内容、设备诊断原始详情和第三方协议错误原文。

稳定状态码和 IGW 自己生成的错误使用语言目录转换；未知内容原样显示，避免丢失现场诊断信息。

## 组件边界

`src/IGW.WebUi/src/i18n/` 包含：

- 语言类型与存储键。
- 中英文消息目录。
- 语言读取、规范化、切换、参数插值和回退逻辑。
- Vue 插件及 `useI18n()` 组合函数。

`App.vue` 负责顶栏入口和 Element Plus `ConfigProvider`；业务页面只调用语言服务，不直接操作本地存储。

## 数据流

1. 启动时读取保存语言；无值或非法值回退中文。
2. 根组件根据响应式语言选择 IGW 消息目录和 Element Plus locale。
3. 页面挂载前从 `/api/v1/ui/preferences` 读取数据库语言；用户点击菜单后立即更新响应式状态、`localStorage` 和 `document.documentElement.lang`，同时 PUT 回偏好数据库。
4. 所有已挂载页面在同一渲染周期内更新，不重新请求工程数据。

## 测试与验收

- 单元测试覆盖默认中文、非法值回退、切换即保存、重建服务后读取已保存语言、参数插值和缺失词条回退。
- 目录一致性测试确保英文目录包含正式中文目录的全部键。
- 源码守卫阻止三个正式路由及其正式组件继续增加未国际化的用户界面文本。
- 运行 Web UI 测试、类型检查和生产构建。
- 浏览器分别验证中文和英文：顶栏、工程配置、监控中心、设置、MES 流程弹窗；切换过程中工程树和流程状态不得重置。

## 完成标准

- 顶栏一次点击即可切换并自动持久化，无保存按钮。
- 三个正式页面及其业务弹窗不存在中英文混杂的固定 UI 文案。
- 工程数据、PLC 名称和接口原文保持不变。
- 中英文切换不触发页面刷新、工程重新加载或流程状态重置。
