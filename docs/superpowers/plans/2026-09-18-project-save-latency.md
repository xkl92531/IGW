# 工程保存延迟修复与发布

用户已批准按变化保存、按影响重载，并打包最新版本。

1. 在 `SqliteProjectRepositoryTests` 添加保存小改动时不得删除/更新无关点位的数据库触发器回归；在运行时测试中验证备注不改变 PLC 设备签名和实时流版本，而地址、周期、确认方式仍改变签名。先运行失败用例。
2. `ProjectSnapshotWriter` 对相同拓扑的快照与数据库基线比较，只更新变化行；结构变化保留原全量事务路径。基线读取前与写事务内均验证修订号，保持冲突检测、密钥保护和单次提交语义。复用现有行序列化代码，保持读取格式一致。
3. 为运行配置建立忽略纯备注的签名。`GatewayHost` 按变化选择 MES、OPC UA、历史、MQTT、计划、计算和报警组件；只有真正南向变化才进入设备增量重建。备注更新同步到缓存和 OPC UA 节点，不替换点值或句柄。配置持久化与运行应用仍在返回成功前完成。
4. 回归配置变更、并发冲突、持久化失败、模板、密钥、MES 定向应用、实际设备配置变化；复用隔离的 1 万/4 万点基准比较保存耗时。运行全量后端测试和前端构建、安装布局检查。
5. 版本升为 1.6.69，发布自包含 Windows x64 Runtime、日志服务与校验过的 OpenObserve，编译安装包，生成校验和与发布说明。说明本地测量与现场 PLC 验证边界。
