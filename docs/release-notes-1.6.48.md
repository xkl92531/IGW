# IGW 1.6.48 发布说明

> 此安装包已由 1.6.49 替代。1.6.48 虽然捕获了目录校验异常，但部分电脑仍会在 Inno Pascal 校验中返回 `Type Mismatch`。

发布日期：2026-09-13

## 安装器修复

- 修复选择 OpenObserve 日志存储目录后点击“下一步”可能弹出 `Runtime error: Type Mismatch` 的问题。
- 磁盘剩余空间校验改用以 MiB 返回的 `Cardinal` 接口，避免 Pascal Script 在部分 Windows 环境中转换 `Int64` 失败。
- 日志目录校验增加异常保护。目录创建、写入测试或空间查询异常时，安装器会显示明确原因并停留在当前页面，不再中止安装程序。
- 继续要求日志目录可写并至少具有 1 GiB 可用空间。

## 保持不变

- IGW Web/API 端口保持 `48020`。
- OpenObserve 首次初始化优先使用本机 `28020/28021`；任一端口被占用时自动选择下一组连续空闲端口。
- 日志服务、OpenObserve 离线包、日志中心及 1.6.47 中的其他功能保持不变。
