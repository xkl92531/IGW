# IGW 1.6.60 发布说明

打包日期：2026-09-17。平台：Windows x64，自包含 .NET 10 运行时。

## OPC UA 读取与订阅

- 按服务器读取窗口和字节上限拆分采集批次，已完成的批次立即发布到 QC 和采集缓存，不再等待同周期全部点读完。
- 共享会话保持最多两个在途请求；普通读取排队时，优先操作执行一次后给读取执行机会，减少多工位持续写入造成的读取等待。
- 并发驱动的采集与写入分别调度；旧扫描响应不能覆盖较新的写后确认值。
- 部分监控点被拒绝时保留正常订阅，只对拒绝点回退读取并重试订阅。
- 服务读取超时后有界返回，保留已读成功值，避免本轮反复拆分重试造成请求放大。

## 写入与采集周期

- 成功点按实际回读结果及时完成，失败点和数组失败切片重试时让出执行机会。
- 单次写入最多初写加十次重写；仍失败则记录最终失败，普通周期 MES 不再追加无限重试。
- 本轮节点结束后，等待任务配置的完整采集周期再开始下一轮；没有固定为 200ms。
- QC 使用后端写后确认结果结束操作，实时变化优先于大快照显示，避免重复等待和旧值覆盖。

## 构建与验证

- 包含当前工作区已授权的修复，尚未提交到 Git；安装包不是仅从 HEAD 提取的旧版本。
- S7 Plus 原生 Release 离线构建、前端生产构建、Runtime 与独立日志服务 win-x64 自包含发布成功。
- Runtime、Core、OPC UA 驱动和日志服务文件版本均为 1.6.60.0。
- 使用 SHA-256 校验后的本地 OpenObserve 1.0.0 缓存及许可证。
- 本轮修复回归最终 533 项后端测试通过；打包前已有 QC/实时链路 33 项测试和类型检查通过。
- 本次打包的安装器检查 11 项通过，发布布局、原生库和前端文件（含 gzip/Brotli 资源）校验通过。
