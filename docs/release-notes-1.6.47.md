# IGW 1.6.47 发布说明

> 此安装包已由 1.6.49 替代。1.6.47 在部分电脑的日志目录空间校验中可能出现 Pascal Script `Type Mismatch`。

发布日期：2026-09-13

## 日志中心

- 新增 IGW 自有界面和交互的统一日志工作台，可查询运行、采集、设备状态、性能、MES 和接口事件。
- 日志查询由 IGW 后端代理，OpenObserve 凭据不会发送到浏览器。
- OpenObserve 作为独立的 `IGW Log Service` 运行；日志服务异常不会阻塞 PLC 采集。
- 失败的遥测批次进入有容量上限的磁盘队列，服务恢复后按顺序重放。
- 支持日志保留天数设置、日志存储位置选择和安全迁移。
- 日志中心顶部显示实际使用的 OpenObserve HTTP 回环端口，便于现场诊断。

## 端口分配

- IGW Web 和业务 API 保持工程配置的端口，默认 `48020`。
- OpenObserve 首次初始化优先使用 `127.0.0.1:28020`（HTTP）和 `127.0.0.1:28021`（gRPC）。
- 如果首选端口中的任意一个已被占用，程序自动选择下一组连续空闲端口，例如 `28022/28023`，并把结果写入受保护的统一配置。
- 已有有效配置会继续使用已经保存的端口；本次开发早期生成的 `5088` 默认配置会迁移到当前可用端口。
- 安装器不再按进程名结束电脑上的全部 `openobserve.exe`，不会误关其他产品的 OpenObserve 实例。

## 结构化运行数据

- 采集批次记录设定周期、实际开始间隔、总耗时、驱动耗时、标签数、样本数、漏期和状态。
- MES 和 HTTP 接口区分传输结果、业务结果和响应写入结果，并保留可关联的 trace ID。
- 敏感字段、认证头和 URL 密钥在写入前清理；大报文使用分页载荷存储。
- 旧版 `/api/v1/runtime-logs` 接口保留兼容，由新的日志后端提供数据。

## 安装和离线交付

- Windows 安装包同时安装 `IGW Gateway`、`IGW Log Service` 和 OpenObserve 1.0.0。
- OpenObserve Windows/Linux 官方发布包和许可证已经通过 Git LFS 提交，换电脑构建时不需要重新下载。
- 安装时可选择日志目录，并检查目录写权限和至少 1 GiB 可用空间；升级和卸载保留日志数据。

## 其他修正

- 补齐日志查询失败的英文提示。
- 构建脚本可识别 winget 当前用户目录中的 Inno Setup。
