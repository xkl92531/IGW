# Modbus TCP

通道选择 `Modbus.Tcp`。设备填写 `IP:502`，在独立 Modbus 参数页设置 Unit ID、超时、字节/字顺序、读取上限和写入策略。

点位按数据区配置，不使用 S7 的 DB 地址：

| 数据区 | 显式地址示例 | 读取 | 写入 |
|---|---|---|---|
| 线圈 | `C:0` | FC01 | FC05 / FC15 |
| 离散输入 | `DI:0` | FC02 | 只读 |
| 输入寄存器 | `IR:0` | FC04 | 只读 |
| 保持寄存器 | `HR:0` | FC03 | FC06 / FC16 |
| 保持寄存器位 | `HR:0.3` | FC03 | 读改写 |

显式地址的偏移始终从 0 开始。旧地址 `40001` / `400001` 等仍兼容，并按设备旧地址基址开关解释；默认一基址对应 `HR:0`。字序支持 ABCD、CDAB、BADC、DCBA。线圈/离散输入使用 Bool；寄存器 Bool 需要位号 0–15。支持连续数组和跨寄存器位数组。

默认寄存器读取上限 120、线圈上限 512，设置实际控制分片。自动写入模式使用单值 FC05/06、多值 FC15/16；强制单写会拆成多个请求。寄存器位读改写和强制单写不保证与其他客户端之间的原子性。通信失败后的不确定写入不会自动重发。
