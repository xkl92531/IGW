# IGW 1.6.54 发布说明

发布日期：2026-09-13

## 日志字段显示

- 日志中心继续为已明确含义的结构化字段显示中文名称。
- 无法可靠翻译的字段直接显示 OpenObserve 中的原始字段名，不再统一显示为“扩展字段”，避免多条字段无法区分。
- 原始字段值和长内容查看方式保持不变。

## SignalR 健康检查降噪

- 成功的 SignalR `health` 轮询不再生成接口日志和跟踪活动，避免高频健康检查淹没采集、上报及异常记录。
- `health` 请求失败或取消时仍记录日志，便于定位实时连接故障。
- 其他 SignalR 请求以及实时流建立、结束和异常日志继续保留。
