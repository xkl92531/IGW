# IGW 1.6.57 发布说明

发布日期：2026-09-14

## 采集任务筛选区固定

- MES 采集流程左侧栏拆分为固定控制区和独立任务列表区。
- “采集任务”标题、任务数量、当前设备/当前通道、搜索框及全部/运行/停用筛选始终保持在顶部。
- 任务较多时仅下方任务卡片列表滚动，滚动到列表中后段仍可直接搜索和切换筛选。
- 任务列表限制横向溢出并保留稳定的滚动条空间，避免滚动条出现时挤动任务内容。
- 筛选逻辑、任务选择、运行状态及采集流程配置数据没有改变。

## 验证

- 针对性测试验证固定控制区不包含任务卡片、滚动列表不包含筛选控件。
- 前端完整测试：74 个测试文件、336 项通过。
- TypeScript 类型检查和前端生产构建通过。
- 安装器自动化测试：11/11 通过。
- Runtime、独立日志服务、OpenObserve 1.0.0 Windows 包及许可证完整性通过校验。
