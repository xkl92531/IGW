# 百万点 SSE 实时通道验证记录

日期：2026-08-31（2026-09-01 完成生产加固复验）

## 交付范围

- 单工程支持 100 万点的数据面规模；实时页面默认最多 100 个 SSE 客户端，每个客户端最多精确订阅 10,000 点，总关系数可达 100 万。
- Quick Client、设备状态和 MES 运行状态使用认证后的 POST SSE 长连接；工程、配置、日志等低频页面仍使用普通 HTTP。
- 首次连接和每 60 秒快照使用 `begin/chunk/complete` 原子协议，前端只在完整快照到齐后一次性替换，避免半新半旧。
- 增量按点位合并，默认 1ms 批窗口；10 秒心跳；慢客户端采用有界队列、丢弃计数和 `reset-required` 重同步，不允许无界占用内存。
- 工程点表变更会提升工程版本，通知旧流终止并按新点表重新建流；旧点位订阅会被清理。
- Quick Client 使用精确完整路径和虚拟表格，不再为每个实时点启动 HTTP 轮询；写入仍走原有设备高优先级写队列并回读确认。

## 2026-09-01 生产加固复验

- 单个 `tag-delta` 最多 256 个值且不超过 1 MiB；600 点网络级 TestServer 场景验证了拆包、完整接收和客户端断开后的会话清零。响应写入默认 10 秒超时，阻塞写测试验证会抛出 `sse_write_timeout` 并释放会话。
- 浏览器遇到序号缺口、重同步、停止或切换代次时会取消旧响应体；400/401/403 停止盲目重试，429 以 30 秒容量退避重连。
- 工程全版本与实时拓扑版本分离：MES 流程或日志保留期修改不再关闭点值流或重启 PLC、OPC UA Server、MQTT、历史和计算点；点表、实时策略或读取权限变化仍会终止旧流并按新拓扑重建。
- 后端按会话批量分发点变化，路由订阅者快照只在连接开关时更新，心跳复用 1 秒指标缓存；前端每帧只解析一次 JSON，快照完成前不触发 Vue，Quick Client 按动画帧合并可见行更新。
- 全局连接只订阅设备状态和 MES 可用性；MES 状态页打开时才订阅全部任务，流程画布只订阅当前任务状态/流转，已删除原来的每秒 MES 全量兜底轮询。
- 压力台架改为与正式 Web Runtime 相同的 Server GC，并按设计采用总览 P95/P99 判定，避免把 100 个客户端中任一单次 OS 调度抖动误报为整条通道失败；阈值仍为 P95 ≤ 20ms、P99 ≤ 50ms。

本次快速复验参数：100 万总点、50 万活跃点、100 个客户端、每客户端 10,000 点、50,000 变化/秒持续 10 秒、随后 200,000 点突发、1 个慢客户端。结果为通过：注册 1.305 秒，总览 P50/P95/P99 为 5/20/50ms，工作集约 1,401.2MB；DataHub、订阅及 SSE 入口丢弃均为 0，最终值不一致 0，清理后会话/点位关系 0/0。该结果是进程内协调器证据，不代替真实 PLC 或现场网络验收。

## 浏览器与本机协议闭环

- 在生产构建页面打开 `SIM.PLC.Runtime` Quick Client，浏览器只建立一次精确范围查询和一次 `/api/v1/streams/realtime` POST 流；未产生旧的 `/api/v1/values` 点值轮询。
- 5 个本机 Modbus TCP 模拟点以完整路径显示并实时变化，SSE 状态为 `live`。
- 从 Quick Client 写入 `SetPoint=123`，页面先显示“写请求已接受”，随后显示“PLC 实际回读确认”，表格值更新为 123、质量为良好。
- 停止 Runtime 后旧值保留，超过 20 秒显示 `stale`；重启 Runtime 后无需刷新页面自动恢复为 `live` 并重新同步。
- 工具调用排队超过 20 秒，未捕获到中间短暂的 `reconnecting` 浏览器画面；该转换由前端确定性测试覆盖，不能作为浏览器实测结果宣称。

## 证据边界与现场验收

以上写入闭环是本机真实 Modbus TCP 报文，但 PLC 端为模拟器；百万点结果为进程内压力台架。它证明本版容量、背压、重载、浏览器流和模拟协议闭环符合设计，不等同于真实产线 PLC、交换机和网络认证。

OPC UA、西门子 S7/S7 Plus、Mitsubishi MC、FINS、EtherNet/IP 等现场协议未在本次本地浏览器验证中连接真实 PLC。部署现场后仍应按设备分别记录：点数、变化率、扫描 P95/P99、SSE P95/P99、丢弃/重同步、写入协议响应与回读确认、真实断网恢复；只有这些现场证据通过后，才能承诺该产线端到端达到 20ms。
