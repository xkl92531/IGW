# IGW 设备模板化配置 · 使用说明

面向"一个项目里成百上千台大同小异设备"的场景:**配 2000 台 ≈ 配 1 台 + 一张清单;改 2000 台的同一个点 ≈ 改一次模板。**

模板由你自己"长"出来 —— 产品不预置、不强制;不使用模板的设备照旧逐点手工配置,两种方式在同一工程内共存。

---

## 一、核心概念

- **模板(Template)**:一份可复用的设备"骨架" —— 点位、分组、扫描率、缩放、数据类型的完整定义,**不含端点**(IP/站号)。绑定一种驱动。工程内模板名唯一。
- **实例(Instance)**:`选模板 + 填端点` 建成的设备。工程文件里**只存"引用模板 + 差异"**,点位在运行时于内存展开 —— 所以百万点工程的文件仍是 MB 级(体积与设备数解耦)。
- **差异(Delta)**:实例相对模板的三类改动 —— **覆盖**(改某点的地址/扫描率/缩放等)、**追加**(实例专有点)、**屏蔽**(某模板点在此实例不生效)。差异存在实例上,**改模板全体实例跟进,且各自差异不被冲掉**。

入口:工程配置页工具栏 **🧩 模板**;设备/通道**右键菜单**;设备树上模板实例的 **🧩徽章**。

---

## 二、典型工作流

### 1. 提取模板(从一台配好的设备)
配好一台样板设备(点位/分组/扫描率都调好) → 在设备树上**右键该设备 → 提取为模板 →** 命名(工程内唯一)。
- 模板带走该设备的全部点位与结构,**不含端点**;**源设备保持不变**(仍是手工设备,不会自动变成实例)。
- 重名会被拒绝,改名重试。

### 2. 套用模板建设备
**🧩 模板 →「套用模板建设备」**(或通道右键「套用模板新建设备…」):
1. 选模板 → 只列出与模板**同驱动**的通道;
2. 填设备名(通道内唯一)、端点(IP/站号)、必要的设备设置(已按模板默认值预填);
3. **保存并应用** → 设备立即按模板全部点位开始采集,并**自动发起验证**(见下)。

> 驱动不匹配、设备重名会被拒绝并提示。

### 3. 套用后验证(套完立刻知道每个点"活没活")
保存应用后自动对目标设备验证,产出报告:
- **可浏览驱动**(OPC UA / EtherNet-IP 等):浏览真机地址空间,逐点标记
  - `✔ 已对上` / `⚠ 真机缺失`(模板有、真机无)/ `✚ 真机多出`(真机有、模板无)。
  - **多出点可勾选「收编」** → 作为**追加差异**加入该实例(不改模板、不波及其他设备)。
- **不可浏览驱动**(Modbus / 三菱等):对展开后的全部点做一轮真实**试读**,逐点标记 `✔ 读通` / `✘ 读失败`(附错误摘要)。
- 验证是**异步作业**,不阻塞其他操作;设备多时显示进度。

### 4. 管理实例差异(徽章 + diff 面板)
设备树上模板实例带 **🧩模板名 差异N处** 徽章,**点徽章**打开差异面板:
- 逐条列出 **类型 / 点位 / 模板值 → 实例值**;
- **单条还原** 或 **整体还原为纯模板**;
- 模板里被删/改名的点若被差异引用,标为**已失效**(展开时自动忽略,建议清理)。

### 5. 改模板 → 全场跟进
**🧩 模板 → 某模板「编辑点位」**:改地址/类型/扫描率、增删点。
- 保存前会预告 **「本次将重启 N 台引用该模板的设备」**;
- 应用后全部引用实例都按新模板生效,**各实例原有差异保留**(覆盖仍压在新模板值之上);
- 只重启引用该模板的设备,无关设备连接不断、数据不丢。

### 6. 导出 / 导入单个模板
**🧩 模板** 列表里「导出」得到 `*.igwtpl.json`;换个工程「导入模板…」即可复用(导入重名拒绝,改名重试)。

## 三、CSV 批量实例化(一张清单建成百上千台)

**🧩 模板 →「批量导入(CSV)」**:上传/粘贴 CSV → 服务器**全量校验** → 全过则**一次性原子写入并应用**;任一行错则**整体不导入**,逐行报错(行号 + 原因),修正后重导。导入完成可对新设备批量验证。

### CSV 格式(UTF-8)

| 列 | 必需 | 说明 |
|---|---|---|
| `设备名` | 是 | 通道内唯一 |
| `通道` | 是 | 已存在的通道,驱动须与模板一致 |
| `模板名` | 是 | 已存在的模板 |
| `端点` | 是 | 非空;如 `192.168.1.11:502` |
| 其余列 | 否 | 列名即设备设置键(如 `scanMode`),单元格为值;空单元格用模板默认 |

- 列名支持中文或英文别名(`设备名/deviceName`、`通道/channel`、`模板名/template`、`端点/endpoint`)。
- 兼容 BOM;字段含逗号用英文双引号包裹(`"D,1"`)。
- 页面「下载样例模板」可得起步文件。

示例:
```csv
设备名,通道,模板名,端点
注塑机01,Modbus通道,注塑机-A,192.168.1.11:502
注塑机02,Modbus通道,注塑机-A,192.168.1.12:502
```

## 四、注意事项

- **先保存再做模板操作**:提取/套用/删除/编辑模板基于**服务端已保存的工程**;若本地有未保存改动,会提示先保存并应用。
- **同驱动约束**:模板绑定驱动类型,套用时目标通道须同驱动(v1 不做跨驱动/通道级模板/模板嵌套)。
- **改模板点重命名 = 删旧加新**:引用了旧名的实例差异会失效(降级为警告并在展开时忽略),在 diff 面板清理即可。
- **向后兼容**:从不使用模板的旧工程零改动加载运行;但**用了模板的工程属单向门 —— 不可用旧版本 IGW 打开**(旧版不认模板,实例会丢点)。详见发版说明。
