# IGW 1.6.51 发布说明

发布日期：2026-09-13

## 工程树大标记组拖动

- 修复工程标签数超过 50000 后切换到分页工程编辑器时，标记组无法拖动的问题。
- 分页工程树中的标记组现在可以拖入目标标记组或设备，并显示拖动中与可放置目标状态。
- 禁止把标记组拖入自身或自身的下级组，服务端仍会在事务中再次校验，避免形成循环层级。

## 性能与配置一致性

- 拖动只向服务端提交源标记组 ID 和目标节点 ID，不把组内标签复制或序列化到浏览器；百万点组的前端回归用例确认没有额外读取标签页或实体内容。
- 服务端使用 SQLite 路径前缀更新子组和标签，可同时支持移动到标记组与设备。
- 组路径变化时同步迁移 MES 任务的组引用、触发点、上报字段、回写点等路径，并原位更新任务引用索引，不为迁移加载全量标签。

## 验证

- 前端完整测试：71 个测试文件、321 项通过；生产构建通过。
- 工程编辑相关前端测试：9/9 通过。
- SQLite 工程仓储测试：8/8 通过，包括设备目标、子标签路径和 MES 任务引用迁移。
- 后端完整测试共 1592 项；1589 项在全套首轮通过。两项仅因本机 OpenObserve 占用默认日志端口而自动顺延，另有 SignalR/WebSocket 并行时序用例波动；波动用例均已单独复跑通过。
- 本次未修改 S7 Plus 原生代码；安装包复用上一版本已验证的 `igw_s7plus.dll`，其余前端、Runtime 和日志服务均重新发布。
