# MES 流程模板(画布一键存模板、套用到任意组)

## Why

设备模板解决了"2000 台同类设备的点位配置"复用,但每台设备的 MES 采集任务(画布流程:触发→上报→判成败→回写)仍要逐组在画布上重新摆一遍——同产线 80 个模块位、流程完全一样,现在是 80 次手工。画布配好的流程应当能"直接变成模板",套用到别的组一键生成任务,与设备模板形成闭环(CSV 批量建 2000 台 → 批量套用流程模板 → 2000 个任务)。

## What Changes

- **画布存为模板**:当前任务(流程节点/连线、上报字段/结构体、触发、回写、心跳/握手)一键保存为流程模板;记录源组路径;模板名工程内唯一,重名拒绝。
- **套用生成任务**:选模板 + 选目标主标记组 → 生成新任务:组内点引用按"源组前缀 → 目标组前缀"深度重写(复用组改路径的按键名重写语义);默认停用(与现有自动建任务惯例一致)。
- **套用报告**:重写后逐引用检查目标组——缺失点列表(字段保留、报告标示,画布可改)+ 组外引用列表(心跳/握手等跨设备点原样保留,提示人工确认)。
- **批量套用**:选模板 + 勾选多个目标组(支持按"某设备模板的全部实例"快速圈选)一次生成 N 个任务,逐组报告汇总。
- **模板管理**:画布内模板面板(列表/删除/导出导入单文件 JSON,对齐设备模板惯例)。
- **裁决:流程模板 = 印章(套用即拷贝、断开关联)**——与设备模板的"活关联"不同。任务天生要被个性化(触发条件、工位号、报文差异),活关联的 diff/传播对流程图语义过重;"改模板全场跟进"留作后续需求验证后再做。

## Capabilities

### New Capabilities

- `mes-flow-template`: 流程模板的提取(画布→模板)、存储、命名唯一性、导出导入。
- `mes-flow-template-apply`: 套用生成任务(前缀重写)、缺失/外部引用报告、批量套用、产物与手工任务等价。

### Modified Capabilities

(无——现有 15 能力不涉及流程模板的规格级行为。)

## Impact

- **`IGW.Abstractions`**:`MesUploadSettings` 新增 `FlowTemplates`(模板=名称+描述+源组路径+任务体),旧工程缺省加载。
- **`IGW.Core`**:`MesFlowTemplateOps`(提取/套用/按键名深度重写器/缺失检查,纯函数可单测);`ProjectStore.Check` 增模板名唯一校验。
- **`IGW.Northbound.RestApi`**:提取/套用/批量套用/导出导入 端点(沿用「克隆工程→改动→ReloadAsync」模式)。
- **`IGW.WebUi`**:`MesFlow.vue` 工具栏「存为模板」「从模板新建」;批量套用与报告为独立组件。
- **不影响**:MES 执行引擎(任务生成后与手工画布任务无异)、采集热路径、设备模板机制。
